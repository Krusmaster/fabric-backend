# Chat test, 18 November 2026: the start cards in claude.ai

Gustav ran the hosted connector's `start` flow in a claude.ai chat, first on the synthetic shop sample and then on his
own data. The MCP App cards rendered with Onto, the step list and the buttons. Round WB12 fixed what he found. Each
finding has its own issue, and every fix is pinned by `tests/test_wb12_chat_cards.py`.

What "verified" means here: unit tests of the card model and its texts, and the card rendered in Chromium under a fake
host (390 px and 1024 px wide, light and dark, in a frame 1800 px tall). Nothing here was run again in claude.ai by this
round. The next chat test is the check for that (see "Try again" below).

## What changed in the listing

`start` now reads workspace, source and schema names on steps 1-3, so its `open_world_hint` is `true`, like
`list_workspaces`. The golden `tests/golden/hosted_listing.json` was updated for exactly that one value. The
description and the listing size are unchanged.

## Not done in this round

- **#66, your own data.** On your own data, the per-decision buttons are on `review_plan`'s card, which already has
  accept and reject per item. `start`'s step 6 still offers "Record my decisions" there, because the start tool does not
  read the open suggestions itself. The per-decision buttons on the start card are drawn for the sample, and for any
  decisions already given in `plan.decisions`.
- **#71.** No map on the start card. See the table above.
