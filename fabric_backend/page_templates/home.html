Security and proof

  • Sign in with Microsoft Entra ID

    Your work account; no {{PRODUCT}} password. For your IT department.

  • Delegated permissions

    Every call runs as the signed-in person, with their own Fabric rights; your admin approves once and can revoke. Each permission and why.

  • Where it runs

    The demo runs in your browser. The hosted service runs in the EU, or in your own Azure; an AI client you connect receives the answers. Where your data goes.

  • No table contents stored

    Names, counts and the sample rows you ask for pass through in memory and are not kept after the request. Privacy.

  • Open source, MIT

    Read the rules behind every link. Source on GitHub.

  • Host it yourself

    The same code in your own Azure or on your own machine, so nothing passes through us. Run it locally.
